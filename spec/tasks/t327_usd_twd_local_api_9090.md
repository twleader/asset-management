# [t327] USD/TWD 即期與近一年歷史唯讀 API（port 9090）

**對應 Requirements:** Requirement 70（USD/TWD 即期與近一年歷史唯讀 API）
**前置任務:** t328（Nginx 9090 統一外部 API；若並行，Task 327 landing 前須先吸收其 gateway 基線）
**Liquibase changeset:** 無（歷史沿用 `exchange_rate_history`；live 只使用兩個固定 Redis key）

## 背景

系統已有 external-materials-service 的台銀 → 兆豐 → Yahoo（USD 備援）→ FinMind 對帳鏈，以及 business 的歷史匯率 GET；但盤中寫 DB 僅每 5 分鐘，Docker 外也沒有固定 USD/TWD、免 Google OAuth、一次回即期與近一年日序列的唯讀 API。

本任務新增 Redis-only 的 2 秒 live producer，且所有外部抓取嚴格留在 Compose/module `external-materials-service`（Maven artifact 與 container 為 `asset-external-materials-service`）。既有 5 分鐘／17:00 DB 歷史排程不改；business 只讀 Redis／DB，BFF 只聚合 business。正式 host URL 為 `http://127.0.0.1:9090/api/public/exchange-rate/usd-twd`；遠端由 Tailscale Serve HTTPS `:9090` 的第五條同名 exact path 提供。Requirement 68／69 與 Task 325／326 已由平行 worktree 預留，故本任務避讓為 327。
