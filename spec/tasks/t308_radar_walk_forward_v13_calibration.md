# [t308] 交易雷達可成交回測、時間外推校準與 TW_RULES_V13 發布

**對應 Requirements:** Requirement 56／65（回測可重現、可成交、分市場且正式規則只採樣本外非劣證據）
**前置任務:** t273（描述性回測）、t274（波動正規化）、t275（Treasury/BOND）、t309（時效/confidence）、t307（估值/profile/events）
**Liquibase changeset:** 無

## 背景

現行 `BacktestService` 只查 `market='台股'`，前瞻報酬是 `adjustedClose[t+h]/adjustedClose[t]-1`；沒有下一日可成交價、成本、chronological holdout 或 walk-forward。2026-08-09 以 51 檔台股跑 2016-08-08～2026-08-07 的描述性結果：MEDIUM_BUY 相對同標的基準平均差在 20/60/120 日為 -0.3324/-1.5705/-2.5981 個百分點，但勝率較高、下檔較小，顯示它較像防守品質而非最高預期報酬；`PROFIT_TAKING_CONFIRMED` 後續平均差反為正。這些結果不能直接拿全期間調參後再宣稱有效，必須時間外推。

## 要做什麼

- [ ] **308.1 Request、成交索引與成本。** 不新增另一個 wire type；V13 是向後相容地擴充既有 `BacktestDto.Request`，保留 `codes,from,to,horizons,thresholds,predicates` 六欄建構式與 `{}`／六欄舊行為。新增欄位與 nullable/default 語意固定為：`markets Set<String>`（`null` 或 empty → `[台股]`；非空只能台股/美股，排序後去重）、`calibrationRatio BigDecimal`（`null` → `0.70`，否則 `0.50..0.80`）、`walkForwardFolds Integer`（`null` → `5`，否則 `3..10`；不可用 primitive 讓 Jackson 缺欄誤變 0）、`costs Map<CostKey,CostAssumption>`（`null` 或 empty → 使用所有選定市場的模型假設；非空只覆寫指定 `market|instrumentKind`）、`includeCloseFallbackSensitivity Boolean`（`null` → false；true 才額外產生 sensitivity）。只有至少一個新增欄位非 null 才是 V13 opt-in；空物件仍走 legacy。JSON `CostKey` 唯一 encoding 固定為 `market|instrumentKind`（例如 `台股|STOCK`），不能依序列化器自行改成 object／冒號格式。`CostKey=(market,instrumentKind STOCK|EQUITY_ETF|BOND_ETF)`；`CostAssumption=(buyFeePct,sellFeePct,sellTaxPct,slippageEachSidePct,sourceLabel,effectiveFrom,effectiveTo)`，每率 0..5。缺省值是**模型假設、不是券商報價或法規宣稱**：台股股票 .1425/.1425/.3000/.0500，台股 ETF .1425/.1425/.1000/.0500，美股股票/ETF .0500/.0500/0/.0500（依序 buy fee/sell fee/sell tax/each-side slippage），label=`CONSERVATIVE_MODEL_2026_08`，response 原樣回傳。

  signal 在 completed close row `t` 形成；h 表示完整持有 h 個 session，故 `entry=adjustedOpen[t+1]`、`exit=adjustedOpen[t+1+h]`，同時回 signal/entry/exit date。任一 open null/<=0 就排除主要樣本並計 `excludedMissingEntryOpen/excludedMissingExitOpen`。敏感度另用 `adjustedClose[t+1]→adjustedClose[t+1+h]`，標 `CLOSE_FALLBACK_SENSITIVITY`，永不進 calibration/promotion/主要 holdout。`grossReturnRatio=exit/entry-1`（ratio）；`grossReturnPct=100*grossReturnRatio`；`netReturnPct=100*(((exit*(1-(sellFee+sellTax+slippage)/100))/(entry*(1+(buyFee+slippage)/100)))-1)`（百分點）。所有 mean/median/percentile/delta 統計欄位統一使用具名 `*Pct`／`*Pp` 百分點，禁止把 ratio 與 percent 混算。adjusted OHLC 必須同時還原 distribution/split。
- [ ] **308.2 全域日曆切分，禁止跨標的洩漏。** 對每個 `(market,horizon)`，先以**不依賴 candidate**的「至少一檔具有效 entry/exit open 的 signal session」建立排序後唯一日期集合。`calibrationCount=floor(dateCount*ratio)`，cutoff=`dates[calibrationCount-1]`；所有標的 `signalDate<=cutoff` 才能選參數，`>cutoff` 才是 holdout。晚上市標的不得用自身較晚 70% 延伸 calibration；paired-by-code 只作聚合，不改日期邊界。expanding walk-forward 以同一全域日期集合：前 50% 為 initial train，剩餘日期切成 K 個連續近等長 evaluation blocks；fold k 的 train 是所有嚴格早於該 block 首日的日期。測試斷言任何 train date < fold evaluation min date。所有 fundamental/premium/FX/Treasury/dividend/public/candidate resolvers 只看 signal instant 前 available 資料。
- [ ] **308.3 報告與同樣本比較。** 維持 pooled/paired-by-code，新增 split/fold/cutoff、market、assetClass、instrumentKind、stockStyle/bondTerm、confidence decile、candidate coverage；每組輸出 n、code count、mean/median、win rate、<=-10% downside、p5/p25/p75/p95、baseline delta、gross/net cost delta、missing-open exclusion 與 sensitivity n。candidate vs baseline 必須使用兩者皆可計算的相同 `(code,signalDate,horizon)` intersection，coverage 差另報，禁止因少算困難樣本而變好。SELL/REDUCE 報「若繼續持有的後續報酬/避免損失」，不得當 short P&L。CSV/JSON 都含 assumptions、cutoffs、failure list。

- [ ] **308.5 Minimum n 與 practical promotion gate。** 每個 `(market,profile applicability,track)` 以同一 candidate 的 required horizon 聯合判定：一般 candidate 在每個 required horizon holdout pooled n>=200 且 paired codes>=8；BOND/profile-specific 每個 horizon n>=150 且 paired codes>=3。walk-forward 至少 3 個 valid folds，每 fold、每個 required horizon n>=50/codes>=3。`returnPracticalDeltaPct=max(0.10,roundTripCostPct)`，`downsidePracticalDeltaPp=1.0`。promotion 需 calibration 選值後，在 untouched holdout **每個 required horizon 都**滿足其一：(A) paired median delta>=returnPracticalDelta、pooled mean delta>=0、downside 不惡化；或 (B) <=-10% downside rate 至少改善 1.0pp，且 paired median/pooled mean delta 都>=-returnPracticalDelta。另以該 track 的 horizon×fold cell 計算，至少 60% valid cells 滿足 A/B，且不得有任一 cell 同時兩個 return delta<-2*returnPracticalDelta 或 downside 惡化>2pp。任一 required horizon insufficient/rejected 即整個 `(market,instrumentKind/profile,track)` key 維持 V12；不可借用另一 horizon/provider 或 sensitivity 補洞。任意非 required horizon 仍可報告，但 production 不為每個 horizon 產生獨立常數。
